# A·B 광고 사운드 제작 기록 — 2026-10-30

두 최신 시안(`ad2a_h.mp4`, `ad2b_h.mp4`)에 배경음악, 장면 효과음, 마무리 악센트를 넣었다. 내레이션은 없다. 이전 시안들은 그대로다. 영상은 재인코딩하지 않고 원본 H.264 스트림을 복사했다.

## 방향과 레퍼런스

- [Penrose Audio — Enclave Sound Design Demo](https://www.youtube.com/watch?v=yPJm7cORFvg): 유튜브 검색 후 영상 파일의 프레임과 제작자의 공개 설명을 확인했다. 제작자가 설명한 짧은 클릭의 강약·미세 리듬·스테레오 배치를 A의 UI 효과음 설계에 참고했다. 모든 글자를 소리로 읽기보다 의미가 바뀌는 순간을 강조한다.
- [토스 브랜드 스토리](https://www.youtube.com/watch?v=DQ-pbxZFJeI): 기존 영상 레퍼런스의 동전·길·카메라 흐름을 확인했다. B는 이동, 정지, 충돌, 재출발의 단계가 소리에도 나타나게 설계했다.
- 레퍼런스의 음악이나 효과음을 추출해 최종 광고에 사용하지 않았다. 사용한 음악·효과음은 아래 별도 라이선스 소스다.

## 음악과 구성

A 주요 지점: 단계 선택, 8.1초 약속, 11.25초 구축 사례, 17.02/18.17초 대화, 19.99초 완료, 22.50/22.80초 광고 토글, 23.90초 고객 알림, 26.37초 '진짜', 27.10초 로고.

B 주요 지점: 체크포인트 7.2/8.75/10.3초, 단독 충돌 12.35초, 동행 복귀 13.48초, 함께 밀기 14.95초, 벽 파괴 15.05초, 검수·배포 완료, 19.25/19.60초 광고 토글, 21.50초 완주, 26.98초 로고.

클릭·팝·스윕은 소스별로 무음 구간을 다르게 잘라 쓰고, 실제 소리가 가장 크게 나는 지점을 화면 이벤트에 맞췄다. 충돌은 나무 타격·균열·파편과 짧은 저음으로 구성했다. 공 이동 질감, 저음 악센트, 곡의 조성에 맞춘 짧은 말렛 음은 코드로 만들었다. 큰 효과음 주변에는 음악 덕킹을 적용했다. 전체 이벤트는 `timeline.json`에 있고, 하나의 화면 이벤트에 여러 소리 층이 들어갈 수 있다.

## 사용 조건

- [Mixkit Stock Music Free License](https://mixkit.co/license/#musicFree): 온라인 광고, 유튜브, 소셜 영상 사용. TV·라디오 방송, 게임, CD/DVD 용도에는 이 음악 라이선스가 적용되지 않는다.
- [Mixkit Sound Effects Free License](https://mixkit.co/license/#sfxFree): 다른 요소와 결합한 완성 영상에서 사용. 효과음 원본 단독 재배포는 하지 않는다.
- 실제 조회한 라이선스 본문: [음악](https://mixkit.co/license/modal/musicFree/), [효과음](https://mixkit.co/license/modal/sfxFree/).
- `sources.json`은 출처·작가·다운로드 URL·SHA-256 기록이다. 원본 음원과 제작용 WAV는 공개 저장소에 포함하지 않는다. 음악을 자체 창작물로 등록하거나 Content ID에 등록하지 않는다.

## 다시 만들기

필수 도구: Python 3, FFmpeg/FFprobe, numpy, scipy, soundfile.

```powershell
python videos/src/sound/mix.py --assets C:/private/audio-cache --output C:/private/audio-renders
```

`--assets`의 누락된 소스를 출처에서 내려받고 SHA-256을 검증한다. 출력 폴더에는 A/B의 음악·폴리·악센트·프리마스터·24비트 마스터 WAV와 MP4, QC JSON이 생긴다. 제작용 WAV와 원본 음악은 개인 작업 폴더에만 두고 최종 MP4만 배포한다. 출력 폴더를 공개 저장소나 `videos` 폴더로 지정하지 않는다.

화면 길이나 모션 시점을 고쳤다면 `timeline.json`도 같이 고친다. 영상 원본 HTML을 렌더링하는 것만으로는 소리가 들어가지 않으므로 위 사운드 단계를 다시 실행해야 한다.

## 검증 범위

최종 AAC를 디코딩해 측정한 값은 `validation.json`에 기록했다.

| 항목 | A | B |
| --- | --- | --- |
| 영상 / 오디오 길이 | 29.5 / 29.5초 | 29.5 / 29.5초 |
| 영상 | 1920×1080, 30fps, 885프레임 | 동일 |
| 오디오 | AAC, 48kHz, 스테레오, 320kbps 목표 | 동일 |
| 통합 음량 | −15.10 LUFS | −15.14 LUFS |
| 최대 트루피크 | −1.46 dBTP | −1.43 dBTP |
| 모노 합산 RMS 유지율 | 92.7% | 97.1% |
| 원본 영상 패킷 SHA-256 | 일치 | 일치 |

프레임과 파형을 함께 확인했고, 원본 모션 코드의 이벤트 시간에 효과음의 트랜지언트를 맞췄다. 끝부분은 잔향과 페이드로 닫는다. 연결 가능한 브라우저/오디오 청취 수단이 없어 실제 스피커·헤드폰 청음 검수는 수행하지 못했다. 위 수치는 기술 검증이며 청감 평가를 대신하지 않는다.
