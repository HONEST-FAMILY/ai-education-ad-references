1안 다시 만든 시안. 90%에서 멈추지 마세요

새 시안30초, 가로 1920x1080
0~4초첫 장면에서 멈추게 하기

'70%에서 90%, 다 된 것 같은데'라는 숫자와 AI로 만든 실제 화면으로 시작하고, 2초 만에 '화면이 90%인 것과 서비스가 90%인 것은 다릅니다'로 바로 찌릅니다.

4~11초혼자 하면 애매한 퀄리티

화면 아래 숨은 네 겹(데이터가 섞이지 않게, 남의 정보가 넘어가지 않게, 여러 명이 써도 멈추지 않게, 결제와 배포까지)을 펼쳐 보이고, 쌤비서의 실제 전후 화면으로 증명합니다.

11~13초그 90%를 만들어 온 팀

스타트업부터 중견기업, 대기업까지 실제 팔리는 서비스 60여 개를 화면 띠로 흘려 보여줍니다.

14~19초하다 말지 않게, 끝까지 완주

혼자 하면 '개발'에서 멈추고 같은 오류가 반복되는 진행 막대를 보여준 뒤, 1:1 실무자가 원인을 찾아 배포와 출시 완료까지 끌고 갑니다.

20~25초만들고 끝이 아니라 마케팅까지

방문자 0명인 서비스에 메타 광고와 검색광고를 켜고, 소재를 키우기, 유지, 끄기로 판단하는 장면으로 '팔릴 때까지'를 보여줍니다.

25~30초한 줄로 마무리

'90%에서 멈추지 마세요.' 뒤에 '내 아이디어를, 판매할 수 있는 진짜 서비스로.'와 상담 안내로 끝납니다.

이전 1안과 달라진 점
  • 첫 프레임부터 숫자와 실제 화면이 보입니다. 빈 화면이나 로고로 시작하지 않습니다.
  • 기획, 설계, 디자인, 개발, 배포를 차례로 설명하던 구성을 버리고, 퀄리티, 완주, 마케팅이 모두 '90%에서 멈추는 이유'로 이어지게 했습니다.
  • 토스 미니앱 광고의 문법을 가져왔습니다. 단어마다 흐리게 떠올라 또렷해지는 글자, 밝은 그라데이션 배경, 그림자가 부드러운 화면 카드, 튕기듯 멈추는 움직임, 입체 아이콘입니다. 형광펜 띠 전환과 모눈 배경은 뺐습니다.
  • 화면은 쌤비서 실제 전후 화면과 어니스트패밀리가 만든 서비스 화면만 썼습니다.

어떻게 만들었고, 어떻게 고치나

  • 장면은 HTML과 CSS로 짜고, 시간에 따라 글자와 화면이 움직이게 했습니다. 크롬으로 한 장씩(초당 30장) 찍어 FFmpeg로 MP4를 만들었습니다. HyperFrames와 같은 원리이고, 유료 라이선스가 필요한 도구는 쓰지 않았습니다.
  • 원본 코드는 저장소의 videos/src 폴더에 있습니다. 새 시안은 ad1b.html, 이전 시안은 plan1.html, plan2.html, plan3.html 한 파일씩이고, 문구와 시간(초)이 파일 안에 그대로 적혀 있어 Claude Code에 '이 문장을 바꿔줘', '이 장면을 1초 늘려줘'처럼 요청하면 됩니다.
  • 다시 뽑을 때는 python render.py video ad1b:h 처럼 실행합니다(파이썬 Playwright, 설치된 크롬, FFmpeg 필요). 글꼴 파일(Pretendard, 에스코어 드림)은 홈페이지 프론트 저장소의 public/renewal/assets, public/fonts 에서 assets 폴더로 복사해 씁니다.
  • 광고로 올리기 전에 배경음악, 마지막 장면의 상담 버튼 문구, 연결 주소의 광고 추적 값(utm)을 정합니다.

영상에 쓴 서비스 화면은 어니스트패밀리 구축 사례이며, 이 페이지는 어니스트패밀리 내부 검토용 자료입니다.
